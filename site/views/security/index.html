Can anything unsigned, tampered or from the wrong place ever run?

Supply-chain controls usually live in prose and in tests that sample a few cases. Here each control is a property the Lean kernel proves for every request, and the threat model that names it is generated from the same source.

The decisions behind this view

VM image admission

Policy decision (OASIS XACML 3.0) · grounded in ContainerCraft/kmi

Decide if a KubeVirt VM image distributed as an OCI artifact may run on a platform cluster, including an air-gapped one.

A request is signature (the Cosign signature check on the image), digest (whether the pulled bytes hash to the digest the reference names), arch (the image architecture), source (pulled from the site's own mirror or from an upstream registry), site (whether the cluster is disconnected), verifier (whether the signature verifier answered), in that order.

Promises the Lean kernel proves for every request

  • It never answers permit when signature is not verified: no unverified image ever runs.
  • It never answers permit when digest is mismatch: no image whose bytes do not match its digest ever runs.
  • It never answers permit when site is airgapped and source is upstream: an air-gapped cluster never runs an upstream pull.
  • It always answers indeterminate when verifier is error: a verifier error never becomes a permit.

Kappa-label check

Policy decision (OASIS XACML 3.0) · grounded in UOR-Foundation/kappa-distribution

Decide if a string is a well-formed kappa-label, the content address every kappa-distribution object is named by, before anything trusts it.

A request is axis (the sigma-axis token before the colon), colons (how many colons the label holds), hex (whether every digest character is 0-9 or a-f), digits (how many hex digits follow the colon), in that order.

Promises the Lean kernel proves for every request

  • It never answers permit when axis is other: an unrecognized sigma-axis is never admitted.
  • It never answers permit when hex is other: an uppercase or non-hex digest is never admitted.
  • It never answers permit when digits < 64: no admitted label is shorter than 32 digest bytes.
